# The Bard's Tale Trilogy 繁體中文化模組使用與修改說明

感謝您使用本中文化模組！本模組採用自製的「動態攔截替換技術 (ZHLocalizer)」，可以在不破壞遊戲原始檔案的情況下，完美實現全中文化。

---

## 🚀 模組安裝與使用方式

### 安裝步驟
1. 解壓縮您下載的 `TheBardsTaleTrilogy_ZH_Mod.zip` 檔案。
2. 將解壓縮出來的**所有檔案與資料夾**（包含 `BepInEx`、`dotnet`、`doorstop_config.ini` 等），直接複製並貼上到您的遊戲安裝根目錄中。
   *預設路徑通常為：`C:\Program Files (x86)\Steam\steamapps\common\The Bard's Tale Trilogy`*
3. 覆蓋任何提示重複的檔案。

### ⚠️ 重要注意事項 (首次啟動黑屏)
> [!WARNING]
> 因為本遊戲採用 IL2CPP 架構，**在您「第一次」安裝完本模組並啟動遊戲時，畫面會停留在【黑屏】長達 1 到 3 分鐘！** 
> 這是因為程式正在背景為您的電腦自動產生專屬的快取檔案，**請務必耐心等待，千萬不要強制關閉遊戲！** 
> 只要撐過第一次，第二次之後的啟動就會恢復正常的 1 秒進入遊戲了。

### 🐧 Steam Deck / Linux 玩家專屬安裝步驟
Steam Deck 使用 Proton 相容層執行遊戲，因此需要一個**額外的重要設定**才能正確載入中文化模組：
1. **複製檔案**：如同上述安裝步驟，將解壓縮出的所有檔案放進 Steam Deck 的遊戲安裝根目錄。
2. **設定啟動選項（關鍵）**：
   * 在 Steam Deck 遊戲庫找到 **The Bard's Tale Trilogy**，點擊齒輪圖示 ⚙️（或按控制器 Menu 鍵）。
   * 進入 **「內容」(Properties)** -> **「一般」(General)**。
   * 在最下方的 **「啟動選項」(Launch Options)** 欄位，輸入以下完整指令：
     ```text
     WINEDLLOVERRIDES="winhttp=n,b" %command%
     ```
3. **啟動遊戲**：設定完成後啟動遊戲。請留意，首次啟動同樣會有 1 到 3 分鐘的黑屏（如上方注意事項所述），請耐心等待！

## 🛠️ 如何自訂或修改翻譯？

如果您在遊戲中發現錯字、語意不順，或是遇到沒看過的新怪物攻擊方式，您可以隨時**自己動手修改**，而且完全不需要寫程式！

所有的翻譯檔案都放在您的遊戲目錄中：
👉 `The Bard's Tale Trilogy\BepInEx\plugins\`

您會在這個資料夾裡看到兩個重要的文字檔：
1. `btr_localization_zh.txt` (遊戲主翻譯檔)
2. `combat_translations.txt` (戰鬥卷軸專用翻譯檔)

### 1. 修改遊戲主翻譯 (`btr_localization_zh.txt`)
這個檔案包含了遊戲中 99% 的介面、道具、怪物名稱與長篇對話。

**修改方法：**
* 使用記事本（或 Notepad++ 等純文字編輯器）打開此檔案。
* 您會看到類似這樣的格式：`英文原文::ZH::繁體中文翻譯`
* **只需要修改 `::ZH::` 後面的中文即可！**
* **範例：**
  如果你覺得 `Long Sword::ZH::長劍` 不好聽，想改成 `鐵劍`：
  👉 直接改成 `Long Sword::ZH::鐵劍`
* 存檔後，重新啟動遊戲即可生效！

### 2. 修改戰鬥動詞 (`combat_translations.txt`)
戰鬥時右下角的滾動文字是透過這個檔案來動態翻譯的。本系統採用「雙階段翻譯」：先將句子結構中文化，再將剩餘的英文動詞翻譯成中文。

**修改方法：**
如果您在戰鬥中看到一句半英半中的怪句子，例如：
> 「`巨龍 對 艾爾·席德 breathes fire，但是未命中！`」

這代表系統成功捕捉了結構，但字典裡沒有 `breathes fire` (噴火) 這個動詞。

**解決步驟：**
1. 打開 `combat_translations.txt`。
2. 直接捲動到檔案的**最下方**（第二階段：動詞翻譯字典）。
3. 按照格式，新增一行您要翻譯的動詞：
   格式為：`\b英文動詞\b::ZH::中文翻譯`
   👉 `\bbreathes fire\b::ZH::噴吐火焰`
   *(注意：首尾的 `\b` 符號非常重要，它確保系統只會精準替換這個單字，不會誤殺其他相近的詞彙！)*
4. 存檔後，重新啟動遊戲，這句話就會變成流暢的：「`巨龍 對 艾爾·席德 噴吐火焰，但是未命中！`」了！

---
> [!TIP]
> **排錯小提示**
> 如果您修改完文字檔後，遊戲突然變成英文，通常是因為您不小心刪掉了 `::ZH::` 符號，或是存檔時編碼跑掉了。請確保您的檔案編碼格式保持為 **UTF-8**！
